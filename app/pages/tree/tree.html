vs-tree

A tree with children loaded on demand, selection, a filter, the full keyboard and optional editing. Documentation

A chart of accounts. The arrows move, Right/Left open and close, Insert adds, F2 renames, Delete removes (leaves only), and Ctrl+X then Ctrl+V moves. Locked accounts can't change. Hover a row for its + and × buttons. "Customers" loads its children when opened.

accounts.nodes = [{ id: 1, label: "Assets", locked: true, children: [ … ] }]; accounts.load = async (node, { signal }) => api.children(node.id, { signal }); // hasChildren: true accounts.onAdd = async (parent, label) => ({ id: await api.add(parent.id, label), label });
