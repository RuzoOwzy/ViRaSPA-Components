vs-rich-text-editor

A rich text editor written entirely in our own code. Its output is always clean, safe HTML. Documentation

It has headings, bold/italic/underline/strike, lists (Tab indents), quote, alignment, links (Ctrl+K), images, undo/redo and clear formatting. Paste from Word or a web page and only clean HTML stays. Alt+F10 goes to the toolbar.
