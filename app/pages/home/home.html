ViRaSPA Extensions

Live demos of the official, optional packages for ViRaSPA, the no-build SPA framework in plain HTML, CSS and JavaScript. A project installs only the packages it uses.

In development, alongside the framework's first version (0.1.0). This page itself is a ViRaSPA app: the framework comes from the jsDelivr CDN, the components and helpers from this repository.

Every package is version 0.1.0, in development.

Install one in your project

node node-tools/install.js add component vs-table@0.1.0 # its helpers and components come with it
