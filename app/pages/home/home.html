ViRaSPA Extensions

Live demos of the official, optional packages for ViRaSPA, the no-build SPA framework in plain HTML, CSS and JavaScript. A project installs only the packages it uses.

In development, alongside the framework's first version (0.1.0). This page itself is a ViRaSPA app: the framework comes from the jsDelivr CDN, the components from this repository.
