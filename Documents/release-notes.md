# ViRaSPA Components release notes

Each component has its own version (in its `component-viraspa.json`) and its own tag, e.g. `vs-card-v0.1.0`.

## 2026-11-06

- **vs-card 0.1.0:** first release. Replaces the framework sample's `app-card`, with `heading` instead of `title`.
- **vs-stat-tile 0.1.0:** first release.
- **vs-login-form 0.1.0:** first release, with scoped isolation.
