vs-input-date

Type the date in the user's own order, or pick it from the calendar. Sundays are disabled for the due date here, and dates before 2026 are refused.

Choose a date.

<vs-input-date name="due" min="2026-01-01" required /> due.isDateDisabled = (iso) => new Date(iso).getDay() === 0; // no Sundays
