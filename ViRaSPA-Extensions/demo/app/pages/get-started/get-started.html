Get started

Each package installs on its own, with the framework's install.js, from your project's repository root. What a package needs (helpers, other components) comes with it.

node node-tools/install.js add component vs-table@0.1.0 node node-tools/install.js add helper forms@0.1.0

Using a component

Nothing else is needed: the framework loads a vs-* component the first time its tag appears on a page. Components without content can be written self-closing in your page and component templates:

<vs-input-number name="amount" decimals="2" /> <vs-card heading="Monthly report"> … </vs-card> (a component with content keeps its closing tag)

Using a helper in your own code

Add its name to helpers in app/config/startup.js, then call its API, e.g. Viraspa.forms.validate(form).

Versions

Every package is version 0.1.0, in development alongside the framework's first version. Each manifest says which framework versions it supports, and the framework refuses an incompatible one with a clear console message.
