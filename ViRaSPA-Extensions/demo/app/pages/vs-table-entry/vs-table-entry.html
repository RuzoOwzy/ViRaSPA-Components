Typing a sale: Enter moves from cell to cell and adds a row at the end, Ctrl+Delete removes a row. Amount is computed (with VAT), and the totals follow.

lines.columns = Viraspa.tableCore.columnsFromChildren(lines).map((c) => c.field === "amount" ? { ...c, value: (row) => row.quantity * row.price * (1 + row.vat / 100) } : c); lines.newRow = () => ({ quantity: 1, vat: "18" });
