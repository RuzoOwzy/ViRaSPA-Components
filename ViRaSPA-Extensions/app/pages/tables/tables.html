Tables

vs-table shows data. It can sort (Shift+click adds a column), search ("elodie aru" finds Élodie's orders in Arusha), filter by column, select across pages, export to CSV and choose columns, and on phones it shows each row as a card. vs-table-entry is for typing rows with the keyboard.

Orders (120 rows in the browser)

Double-click a row or press Enter on it to open it.

Typing a sale

Enter moves from cell to cell and adds a row at the end. Ctrl+Delete removes a row. Amount is computed (with VAT), and the totals follow.

Pagination on its own

vs-pagination is used inside vs-table, and also works with any list of your own.

table.rows = orders; // or a server source: table.source = async ({ page, pageSize, search, sort, filters, signal }) => { const r = await api.orders({ page, pageSize, search, sort, filters }, { signal }); return { rows: r.items, total: r.count }; };
